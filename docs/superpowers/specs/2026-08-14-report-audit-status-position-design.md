# 报告审批状态专属位置设计

## 目标

保持报告表头和运行状态不变，将报告区块中的 `auditStatus` 从普通字段移动到“基础信息”区块右上角，以审批状态标签展示。

## 最小方案

- 不修改后台 ReportSchema、工作流和报告配置协议。
- 前端从现有 `section.items` 中查找机器字段名为 `auditStatus` 的值。
- 在第一个 `KEY_VALUE` 基础信息区块标题右侧展示审批状态。
- 所有普通区块不再重复展示 `auditStatus` 数字值。
- 映射：0 审批中/蓝色，1 审批成功/绿色，2 驳回/红色，3 撤回/黄色，4 暂存/灰色。
- 字段缺失、值无效、没有基础信息区块或出现多个不同状态时不展示。

## 修改范围

- 新增前端审批状态纯函数及最小回归用例。
- 修改通用报告组件 `AiReport.vue`。
- 同步项目需求进度文档。

不修改专用结算报告、后台状态字段、数据查询和报告配置页面。

## 验收

1. 报告表头内容和“基础数据已就绪”保持原样。
2. `auditStatus=0..4` 时在基础信息右上角显示对应文字和颜色。
3. 数据汇总不再显示“审核状态 1”之类的原始数字卡片。
4. 缺少或无效状态时不留空标签。
